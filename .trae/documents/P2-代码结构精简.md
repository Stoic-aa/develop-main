# P2 代码结构精简（MyBlog）

## Context

当前站点前端脚本存在三类问题，导致「臃肿 + 隐患」：

1. **死代码**：`main.js` 的 `isHomePage()` 被硬编码为恒返回 `false`，导致其首页分支、`renderFeaturedArticle()`（页面无 `#featured-article-section` 容器）、`homepageArticlesData` 全部不可达；`articles-data.js` 的 `renderEmedPageArticles()`/`buildEmedArticleCard()` 目标 `emed.html` 不存在，同样不可达。
2. **重复执行**：`articles-data.js` 的 `initRendering()` 同时挂在 `layout:ready` 与 `DOMContentLoaded + 200ms` 定时器上，会跑两次。
3. **单文件过大 + HTML 内联样式**：`main.js` 757 行承担 10 项职责；`articles/article-template.html` 内联了约 225 行 `<style>`。

目标：**删除死代码、修掉双跑、按职责拆分脚本、把内联样式外置**，在不改变任何页面可见行为的前提下让结构更清晰。

用户已确认：① main.js **拆成 3 个职责模块**；② 已禁用的首页特色区 / emed 分类渲染代码**直接删除**。

## 目标脚本结构

```
js/
├── articles-data.js   # 纯数据源 + 数据工具（不再含任何渲染/DOM 逻辑）
├── utils.js           # 公共路径/URL 工具（新建）
├── article-list.js    # 文章列表渲染、分页、搜索（新建）
├── ui.js              # 主题、移动端侧边栏、设置菜单、阅读模式、通知、导航高亮（新建）
├── layout-init.js     # 不变
├── article-detail.js  # 不变（依赖的全局函数名保持不变）
├── bootstrap.js       # 更新 COMMON_SCRIPTS 顺序
├── baidu-analytics.js # 不变
└── tailwind-config.js # 不变
```
`js/main.js` 删除。

## 具体改动

### 1. 新建 `js/utils.js`（从 main.js 抽出，原样迁移）
- `normalizePath(path)`、`getCurrentSlug()`、`getArticleSlug(url)`
- 迁移后照旧暴露：`window.normalizePath` / `window.getCurrentSlug` / `window.getArticleSlug`（`article-detail.js:27`、`ui.js` 依赖）

### 2. 新建 `js/article-list.js`（从 main.js 抽出 + 删死代码）
- 常量 `ARTICLE_PER_PAGE`、`ARTICLE_CARD_SCALE`、`GLOBAL_FLAGS.articleHoverBound`
- 状态 `displayedArticles` / `allSortedArticles` / `currentPage` / `allArticlesBackup`
- `sortArticlesByDate`、`createArticleCard`、`renderArticleList`、`loadMoreArticle`
- `initArticleData`、`performSearch`、`resetArticleList`、`renderSearchResults`
- **删除** `isHomePage()` 与其所有分支、`renderFeaturedArticle()`、`homepageArticlesData` 读取分支
  - 列表容器选择器固定为 `.space-y-16`，wrapper 固定 `className = 'space-y-0'`
  - 数据源固定取 `window.articlesData`
- **顺带修复**：`window.resetArticleList = resetArticleList`（当前 `renderSearchResults` 生成的 `onclick="resetArticleList()"` 因该函数未挂到 window 而失效）
- 入口：`window.addEventListener('layout:ready', () => { initArticleData(); bindArticleHover(); })`
- 保留暴露：`window.performSearch`、`window.resetArticleList`

### 3. 新建 `js/ui.js`（从 main.js 抽出）
- 主题：`applyThemeMode`、`updateGrayModeIndicator`、`setupDarkModeToggle`、`window.toggleGrayMode`
- 移动端侧边栏：`setupMobileSidebar`（含 DOM 重试）
- 导航高亮：`window.setActiveNav`（保留现有 index/分类两分支逻辑，`articlesData`/`getArticleSlug`/`normalizePath` 仍从全局取）
- 设置菜单：`initSettingsMenu`、`bindSettingsDropdown`、`handleSettingsDropdownClick`、`window.toggleReadMode`、`updateReadModeIndicator`
- 通知：`funnyMessages`、`showNotification`、`hideNotification`、`bindNotificationButton`、`window.scrollToTop`
- **顺带修复**：`window.hideNotification = hideNotification`（`components/header.html:105` 的 `onclick="hideNotification()"` 目前失效）
- 入口：`window.addEventListener('layout:ready', () => { setupDarkModeToggle(); setupMobileSidebar(); window.setActiveNav(); initSettingsMenu(); bindNotificationButton(); })`
- 保留暴露：`window.setupDarkModeToggle`、`window.setActiveNav`、`window.toggleGrayMode`、`window.toggleReadMode`、`window.scrollToTop`、`window.hideNotification`

### 4. 删除 `js/main.js`

### 5. `js/articles-data.js` 瘦身
- **删除** `buildEmedArticleCard`、`renderEmedPageArticles`（无 `emed.html`）
- **删除** `homepageArticlesData` / `featuredArticleData` / `featuredArticleConfig` 及其 window 暴露
- **删除** `getLatestArticles`、`getLatestFeaturedArticle`（仅被上述死代码使用）
- **删除** `initRendering` 的双触发，改为单一入口（布局组件由 `layout-init` 注入、`layout:ready` 在注入后派发，`bootstrap.js` 已保证 `articles-data.js` 先于 `layout-init.js` 加载，监听不会错过）：
  ```js
  window.addEventListener('layout:ready', renderTrendingTopics);
  ```
- 保留：`articlesData`、`parseDate`、`getSortedArticles`、`renderTrendingTopics`、`updateSiteStats`、`window.articlesData`、`window.updateSiteStats`
  - `window.renderTrendingTopics` 暴露无消费者 → 移除

### 6. `js/bootstrap.js`：更新加载顺序
```js
const COMMON_SCRIPTS = ['articles-data.js', 'utils.js', 'article-list.js', 'ui.js', 'layout-init.js'];
```
（`utils` 先于 `article-list`/`ui`；`layout-init` 最后，确保其运行时用到的 `performSearch`/`setActiveNav`/`updateSiteStats` 已就绪。）

### 7. `articles/article-template.html`：内联样式外置
- 把 `<style>…</style>`（19–243 行，`.material-symbols-outlined`、`.article-content *`、`[data-syntax-theme="github"]` 明暗两套变量、移动端 `.article-container` 覆盖）整体迁入 `css/style.css` 末尾
- 删除该 `<style>` 块，页面 head 仅保留 `<link rel="stylesheet" href="../css/style.css" />`
- 顺带删除 body 末尾重复的 `<div id="footer-placeholder"></div>`（第 312 行；`layout-init` 注入的是第一个 id，重复 id 非法）

### 8. 清理无效属性
- `friendlink.html:3`、`bilibi.html:3`：`<html class="light">` → `<html class="scroll-smooth">`（`light` 非本站主题类，主题由 `html.dark` 驱动）
