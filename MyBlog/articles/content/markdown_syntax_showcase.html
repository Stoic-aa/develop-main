为什么写这篇测试

这是一篇自检用的文章，用来确认 Markdown 转换脚本与文章模板的配合是否完整。 如果下面每个区块都显示正常，说明写作链路工作良好。

需要重点确认的元素有：

  • 各级标题的层级与字号
  • 有序 / 无序 / 嵌套列表
  • 表格、引用、分割线
  • 行内代码 inline code 与多语言代码块高亮

一、文本与列表

普通段落支持 加粗、斜体，以及指向 Trae 官网 的链接。

无序列表（含两层嵌套）：

  • 嵌入式方向
    • STM32 / AUTOSAR
    • RTOS 实时性分析
  • Web 方向
    • 前端工程化

有序列表：

  1. 先在 md/ 目录写好 Markdown
  2. 执行转换脚本生成正文片段
  3. 在文章详情页验证渲染

引用块用来强调背景或结论。 第二行会与第一行同属一个引用段落。

还支持嵌套引用。

#include <iostream>
#include <vector>
#include <string>

template <typename T>
class Stack {
public:
    void push(const T& value) { items_.push_back(value); }

    T pop() {
        T top = items_.back();
        items_.pop_back();
        return top;
    }

private:
    std::vector<T> items_;
};

int main() {
    Stack<std::string> stack;
    stack.push("embedded");
    std::cout << stack.pop() << std::endl;
    return 0;
}

七、Python

from dataclasses import dataclass
from pathlib import Path


@dataclass
class Article:
    slug: str
    title: str
    tags: list[str]


def load_articles(content_dir: Path) -> list[Article]:
    """读取 content 目录下的所有文章片段。"""
    articles = []
    for path in sorted(content_dir.glob("*.html")):
        text = path.read_text(encoding="utf-8")
        articles.append(Article(slug=path.stem, title=path.stem, tags=[]))
    return articles


if __name__ == "__main__":
    for item in load_articles(Path("articles/content")):
        print(f"{item.slug}: {len(item.tags)} tags")

八、Java

public class TemperatureReader {

    private static final double OFFSET = 0.5;

    public static double toCelsius(int raw) {
        return raw * 0.0625 - OFFSET;
    }

    public static void main(String[] args) {
        int[] samples = { 320, 336, 352 };
        for (int raw : samples) {
            System.out.printf("raw=%d -> %.2f°C%n", raw, toCelsius(raw));
        }
    }
}
